# TrackMyHabbits
Habbits tracker with analysis progresses

Создай веб-приложение для отслеживания привычек пользователей. Пользователь может добавлять привычки (например, “читать”, “тренироваться”, “учить Go”) и отмечать выполнение каждый день. Система будет сохранять данные в MongoDB и показывать аналитику: прогресс по привычкам, streak’и, пропуски и т.д.

⸻

Ключевые функции:
	•	Регистрация и авторизация пользователей
	•	Добавление/удаление привычек
	•	Отметка выполнения привычки по дням
	•	История привычек (по дням, неделям, месяцам)
	•	Графики и статистика выполнения
	•	Push-уведомления или email-напоминания (опционально)

⸻

Технические детали:
	•	Backend: Go + Gin
	•	Database: MongoDB
	•	Коллекции: users, habits, habit_logs
	•	Frontend (опционально): React, Svelte или просто HTML-шаблоны с Go
	•	Аутентификация: JWT
	•	Дополнительно:
	•	Cron-задачи для анализа прогресса
	•	Docker для контейнеризации
	•	REST или GraphQL API
